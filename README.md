# Зомби, чипсы, базуки

Небольшой браузерный прототип на выживание в духе Vampire Survivors.
Игрок только ходит по арене: базука сама целится и стреляет в ближайшего зомби,
а чипсы, выпавшие из зомби, притягиваются при приближении.
Цель: пережить 90 секунд и собрать как можно больше чипсов.

## Правила и управление

- «Погнали» / Enter: начать забег.
- WASD / стрелки: движение; диагональное движение имеет ту же скорость.
- Мышь: зажми левую кнопку на арене — персонаж идёт к указателю. Отпусти — остановится.
  Скорость такая же, как с клавиатуры; если одновременно нажать клавишу движения, клавиатура имеет приоритет.
- Стрельба и прицеливание полностью автоматические, нажимать кнопку выстрела не нужно.
- При повышении уровня игрока: щёлкни карточку базуки или нажми 1, чтобы повысить уровень оружия.
- P / Esc: пауза; Enter или кнопка: продолжить. Потеря фокуса тоже ставит игру на паузу.
- R: новый забег; после результата также доступны Enter и кнопка.

Ракеты взрываются при столкновении, у края арены или по истечении времени полёта.
Взрыв уничтожает всех зомби в радиусе, игроку он не вредит. Боеприпасы бесконечные.
Каждый зомби оставляет пакет чипсов: подойди к нему, чтобы получить +1 к счёту,
+1 к опыту и восстановить 1 здоровье (максимум 5). Чипсы притягиваются с расстояния 100 пикселей.
Первый новый уровень требует 5 пакетов, каждый следующий — на 3 больше.
При повышении уровня игрока игра останавливается и открывает три слота выбора оружия.
Пока оружие одно: доступна только карточка «Базука», два остальных слота пустые.
Выбор повышает уровень базуки на один; её параметры определяются уровнем целиком.
Уровень игрока и уровень оружия — отдельные счётчики.

| Уровень базуки | Перезарядка | Радиус взрыва | Ракет в залпе |
| --- | --- | --- | --- |
| 1 | 1,10 с | 45 пикселей | 1 |
| 2 | 0,94 с | 60 пикселей | 1 |
| 3 | 0,79 с | 75 пикселей | 1 |
| 4 | 0,68 с | 90 пикселей | 2 |

Каждый уровень сокращает перезарядку на 15% (минимум 0,22 с) и увеличивает радиус на 15 пикселей.
На уровнях 4, 7, 10 и 13 добавляется по ракете в залпе (максимум 5), ракеты летят веером.
За одно повышение уровня игрока можно повысить уровень оружия только один раз.
Все улучшения действуют только в текущем забеге и сбрасываются при перезапуске.
Столкновение с зомби отнимает 1 здоровье,
после него есть короткая неуязвимость. При нуле здоровья забег заканчивается.
Через 90 секунд выживший игрок побеждает. Частота появления и скорость новых зомби
постепенно растут. Финальный экран показывает время, чипсы и число побеждённых зомби.

## Запуск и проверка

Нужен Node.js >= 20.19 (рекомендуется Node.js 22).

```bash
npm install
npm run dev
```

Открой адрес, который напечатает Vite (обычно http://localhost:5173/).

```bash
npm run typecheck
npm run build
npm run preview
```

Ручная проверка: начни забег и двигайся, не нажимая кнопок стрельбы.
Проверь WASD и зажатую ЛКМ: персонаж идёт к указателю, останавливается у него и при отпускании кнопки.
Подойди к выпавшим чипсам; проверь притягивание, опыт, счёт и лечение после столкновения.
Собери 5 пакетов: появится карточка базуки и два пустых слота, а таймер и враги остановятся.
Выбери базуку мышью или клавишей 1: её уровень повысится с 1 до 2,
перезарядка сократится, а радиус увеличится. Клавиши 2 / 3 и пустые слоты ничего не выбирают.
Проверь паузу, поражение при бездействии, победу через 90 секунд и новый забег
с нулевым счётом, первым уровнем, исходной базукой, полным здоровьем и пустой ареной.

## Где менять игру

- `src/game/GameScene.ts`: правила, управление, зомби, ракеты, взрывы, чипсы и экраны результата.
  Основные параметры вынесены в константы в начале файла.
- `src/game/config.ts`: размер экрана и настройки Phaser.
- `src/style.css`, `index.html`: оформление страницы и её заголовок.

Используется стартовый стек курса: TypeScript strict + Phaser + Vite.
Графика нарисована простыми фигурами, внешние картинки и новые библиотеки не нужны.
На сцене максимум 60 зомби и 80 пакетов чипсов; при переполнении убирается самый старый пакет.

## Публикация и оставшиеся шаги практики

Готовая сборка находится в `dist/`. В проекте сохранён workflow
`.github/workflows/deploy.yml`: после push в `main` или `master` он собирает
и публикует игру на GitHub Pages. В Settings → Pages нужно выбрать GitHub Actions.
Инструкции по исходной настройке: `TEACHER_SETUP.md`, по проблемам: `TROUBLESHOOTING.md`.

- [ ] Опубликовать и проверить публичную ссылку с другого устройства.
- [ ] Дать другому человеку поиграть без подсказок автора.
- [ ] Записать минимум 3 конкретных наблюдения и скорректировать сложность.

Публичная ссылка и результаты теста с реальным игроком пока не получены.
Нет мобильного управления, звука, других видов оружия, магазина, боссов, сохранения рекордов или сбора метрик.
Когда появятся другие виды оружия, в эти слоты можно будет случайно предлагать их покупку или прокачку.
Случайная выдача пока не реализована: сейчас доступна только базука.
Баланс предварительный. Требования практики: `ASSIGNMENT_01.md`.
